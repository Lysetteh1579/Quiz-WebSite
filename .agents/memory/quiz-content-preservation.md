---
name: Quiz content preservation
description: The user expects quiz content to remain intact during visual changes.
---

During quiz-app redesigns, preserve all existing question prompts, answer choices, and correct-answer information unless the user explicitly asks to edit them.

**Why:** The user asked for a Blooket-inspired redesign while keeping all information they had supplied for the questions.

**How to apply:** Prefer presentation-only changes and verify that question data is unchanged before finishing.
