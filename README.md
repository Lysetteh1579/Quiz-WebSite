# Quiz-WebSite

A small, colorful quiz site with ready-to-play quizzes and an editor for making them your own.

## Run it

Open `index.html` in a browser, or serve this folder locally:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Use it

- Browse, search, and filter the sample quizzes, or choose **Surprise me** for a random one.
- Play a quiz, shuffle its questions, and review your answers at the end.
- Open the editor to change quiz details and questions, add or remove questions, and select the correct answer.
- Saved edits stay in this browser on this device using local storage; there are no accounts or shared server storage.
